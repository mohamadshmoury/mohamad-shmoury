# Bundled Arabic fonts

- **Noto Naskh Arabic Regular** — Google Noto Fonts, SIL Open Font License 1.1.
- **Amiri Regular** — The Amiri Project Authors, SIL Open Font License 1.1.
- **Aref Ruqaa Regular** — The Aref Ruqaa Project Authors, SIL Open Font License 1.1.

The license text is included in `OFL-1.1.txt`. The fonts are bundled into the
Supabase Edge Functions so PDF output is deterministic and does not depend on
fonts installed on the user's device.
